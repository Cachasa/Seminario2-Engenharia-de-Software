#### Requisitos funcionais

- **RF01** — O sistema deve permitir que o usuário compartilhe sua biblioteca de jogos com outros membros da família.
    
- **RF02** — O sistema deve permitir que o responsável pela família convide outros usuários para participar do grupo familiar.
    
- **RF03** — O sistema deve verificar se a conta do usuário atende aos requisitos necessários para criar uma família.
    
- **RF04** — O sistema deve verificar se um jogo é elegível para compartilhamento.
    
- **RF05** — O sistema deve identificar quais jogos pertencem a cada membro da família.
    
- **RF06** — O sistema deve permitir o retorno de um antigo membro à família mediante um novo convite, respeitando as restrições aplicáveis.
