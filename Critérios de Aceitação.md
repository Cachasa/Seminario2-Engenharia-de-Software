RF01
- O compartilhamento deve disponibilizar aos membros os jogos elegíveis da biblioteca do usuário.  
      
    
- Os jogos compartilhados devem aparecer na biblioteca dos membros participantes.  
      
    
- Jogos não elegíveis não devem ser disponibilizados.

RF02
- O sistema deve permitir selecionar um usuário para enviar um convite.
    
- Após o envio, o sistema deve indicar que o convite foi enviado.
    
- O sistema deve impedir o envio de convites quando o grupo atingir o limite de participantes.

RF03
- O sistema deve permitir a criação de uma família quando a conta do usuário não possuir restrições de conta limitada.

- O sistema deve impedir a criação de uma família caso a conta seja identificada como limitada.

- Ao tentar criar uma família com uma conta limitada, o sistema deve apresentar uma mensagem informando que contas limitadas não podem criar famílias. 

RF04
- Jogos compatíveis com o compartilhamento devem ser disponibilizados aos membros.
    
- Jogos que não permitem compartilhamento devem ser identificados como não elegíveis.
    
- O sistema não deve disponibilizar jogos que não atendam aos critérios de compartilhamento.

RF05
- O sistema deve exibir o proprietário de cada jogo compartilhado.
    
- Os jogos devem ser identificados corretamente conforme a biblioteca de origem.
    
- O sistema deve atualizar as informações quando houver alterações nas bibliotecas dos membros.

RF06
- O sistema deve permitir que um antigo membro receba um novo convite para retornar à família.

- O sistema deve permitir que o antigo membro retorne à família após aceitar o novo convite.

- O sistema deve impedir o retorno do antigo membro caso ele não atenda às restrições e condições estabelecidas pela Steam para participar de uma família.
