# Checklist de Testes — Família Steam

## 1. Criação de família sem ter gasto 5 dólares

- [ ] Necessário um dispositivo que suporte a Steam.
- [ ] Criar uma conta com e-mail e senha.
- [ ] Ter uma conta verificada no e-mail.
- [ ] Fazer o login da conta.
- [ ] Acessar o campo superior esquerdo "Steam".
- [ ] Ir em "Configurações".
- [ ] Clicar em "Criar ou entrar em Família".
- [ ] Definir um nome para a família.
- [ ] Verificar se ocorre o erro: "Falha ao criar família. Contas limitadas não podem criar uma família".

---

## 2. Saída e reentrada da mesma família

*Situação em que uma pessoa sai da família sem querer.*

- [ ] Necessário um dispositivo que suporte a Steam.
- [ ] Criar uma conta com e-mail e senha.
- [ ] Ter uma conta verificada no e-mail.
- [ ] Fazer o login da conta.
- [ ] O responsável da família deve ter a outra conta adicionada.
- [ ] O responsável deve enviar o convite para entrada na família.
- [ ] O convite deve ser aceito pelo aplicativo.
- [ ] Entrar na família.
- [ ] Caso queira sair, clicar no seu nome.
- [ ] Clicar no botão "Sair".
- [ ] Caso queira voltar, verificar se é possível reenviar o convite.

---

## 3. Mensagens no histórico de Logs

- [ ] Necessário um dispositivo que suporte a Steam.
- [ ] Criar uma conta com e-mail e senha.
- [ ] Ter uma conta verificada no e-mail.
- [ ] Fazer o login da conta.
- [ ] Gastar no mínimo 5 dólares para criar uma família (caso seja necessário criar uma).
- [ ] Criar ou aceitar um convite para a família.
- [ ] Acessar o campo superior esquerdo "Steam".
- [ ] Ir em "Configurações".
- [ ] Clicar em "Família e compartilhamento".
- [ ] Ir em "Gerenciar a família Steam".
- [ ] Clicar no campo "Histórico".
- [ ] Verificar a mensagem no histórico: "xxxx criou a família com o nome xxxxx".

---

## 4. Abrir jogo de outro familiar

- [ ] Necessário um dispositivo que suporte a Steam.
- [ ] Criar uma conta com e-mail e senha.
- [ ] Ter uma conta verificada no e-mail.
- [ ] Fazer o login da conta.
- [ ] Criar ou aceitar um convite para a família.
- [ ] Verificar se há o jogo na biblioteca.
- [ ] Analisar se não há nenhum membro jogando.
- [ ] Baixar o jogo.
- [ ] Escolher a cópia (caso tenha várias).
- [ ] Abrir o jogo.
