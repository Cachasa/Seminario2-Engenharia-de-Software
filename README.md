# Seminário 2 – Engenharia de Software IFGOIANO

## Compartilhamento de Bibliotecas da Steam (Família Steam)

### Sobre o trabalho

Este repositório contém os materiais desenvolvidos para o Seminário 2 da disciplina de Engenharia de Software, a qual o tema escolhido foi a funcionalidade de compartilhamento familiar da plataforma Steam.

O trabalho tem o intuito de escolher uma funcionalidade específica de uma aplicação, e desenvolver 

A Família Steam é um recurso que permite que usuários compartilhem suas bibliotecas de jogos com outros integrantes de um mesmo grupo familiar, respeitando as regras, restrições e condições estabelecidas pela plataforma.

### Objetivo

O trabalho tem o intuito de escolher uma funcionalidade específica de uma aplicação, e analisar o funcionamento do dela, identificando suas principais funcionalidades e comportamentos, além de planejar e realizar testes (com checklists) para verificar se o sistema atende aos requisitos estabelecidos.

### Atividades desenvolvidas

Durante o desenvolvimento desse trabalho, foram realizadas as seguintes atividades: 

- Análise da funcionalidade e definição do escopo;
    
- Identificação e documentação dos requisitos funcionais/Critérios de aceitação;
    
- Elaboração do plano de testes;
    
- Definição de cenários e procedimentos de teste;
    
- Execução dos testes na plataforma Steam;
    
- Registro e documentação dos resultados obtidos por meio de prints.
    

### Ferramentas utilizadas

- **Steam:** plataforma utilizada para análise e execução dos testes.
    
- Obsidian: Para documentar o projeto.
    
- **GitHub:** armazenamento e organização dos materiais do trabalho.
	
- ShareX: Para capturar as prints com anotações
